# Security policy

## Supported versions

Only the latest release gets security fixes. Update from Settings > Updates in
the app, or download the newest installer from the Releases page.

## Reporting a vulnerability

Please report it privately, not as a public post:

1. Open the Security tab of this repository.
2. Choose "Report a vulnerability".
3. Say which ConnSmith version and Windows version you use, what you did, and
   what you saw.

You can also go straight to
https://github.com/CautiousCapsLock/connsmith-releases/security/advisories/new

ConnSmith is maintained by one person, so replies are best effort. I aim to
acknowledge a report within 7 days and to say what I plan to do within 30 days.
Please give me time to ship a fix before you publish details.

## Scope

The ConnSmith app and its installer. Problems in the devices you connect to are
out of scope.
